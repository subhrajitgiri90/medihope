How the system works

  1. Admin creates and verifies a medical campaign.
  2. Donor selects a campaign and enters donation details.
  3. The system creates a demo transaction.
  4. Dashboard updates campaign and donor statistics.
  5. Admin can review the transaction history.
Demo only: no real money is processed and full card numbers are never stored.

Data Storage

This single-file prototype uses browser localStorage.

Recommended Real Backend

For deployment, replace localStorage with a secure server such as Node.js + Express and a database such as MySQL/PostgreSQL. Authentication, authorization, validation, audit logs, encryption, and a certified payment provider should be added before handling real donations.

About the Project

MediHope demonstrates a complete workflow for a medical campaign fundraising platform. The project includes campaign management, donor registration, demo payment processing, transaction records, dashboard analytics, and admin controls.

Project Modules

Frontend

HTML, CSS and JavaScript dashboard, forms, campaign cards, charts and responsive UI.

Backend Concept

Database
